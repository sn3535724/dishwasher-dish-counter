# Dishwasher Dish Counter

Учебное веб-приложение для подсчёта посуды и столовых приборов
на фотографии открытой посудомоечной машины.

Пользователь загружает изображение через браузер. Модель YOLOv8
находит поддерживаемые объекты, рисует рамки и возвращает общее
количество предметов и количество предметов каждого вида.

## Поддерживаемые объекты

- чашка;
- миска;
- бокал;
- вилка;
- нож;
- ложка.

Стандартная модель YOLOv8 не содержит отдельного класса для тарелок.
Это ограничение выбранной предобученной модели.

## Возможности

- загрузка изображений JPG, JPEG, PNG и WEBP;
- выбор режима обработки;
- настройка порога уверенности;
- подсчёт найденных предметов;
- вывод обработанного изображения с рамками;
- хранение истории в SQLite;
- очистка истории;
- экспорт результатов в Excel.

## Технологии

- Python;
- Flask;
- Ultralytics YOLOv8;
- OpenCV;
- SQLite;
- openpyxl;
- HTML, CSS и JavaScript.

## Запуск в Windows

1. Установить Python 3.11 или более новую версию.
2. Скачать проект.
3. Запустить файл start.bat.
4. Дождаться установки зависимостей.
5. Открыть адрес http://127.0.0.1:5000.

Файл start.bat создаёт виртуальное окружение и устанавливает зависимости
из requirements.txt. При первом запуске это может занять несколько минут.

## Ручной запуск

    python -m venv .venv
    .venv\Scripts\activate
    pip install -r requirements.txt
    python app.py

## Структура проекта

- app.py — маршруты Flask;
- utils/detector.py — обработка изображения моделью YOLOv8;
- utils/database.py — работа с базой SQLite;
- utils/report_export.py — создание Excel-отчёта;
- templates/index.html — страница приложения;
- static/css/style.css — оформление;
- start.bat — автоматический запуск в Windows.

## Ограничения

Результат зависит от освещения, ракурса и перекрытия предметов.
Если посуда расположена слишком плотно или видна только частично,
модель может пропустить объект или определить его неправильно.

Репозиторий проекта:
https://github.com/sn3535724/dishwasher-dish-counter

Для проверки можно использовать изображение `test_dishwasher.png`. На нём
расположены две чашки, три тарелки и два бокала. Стандартная модель YOLOv8
распознаёт две чашки и два бокала, но не учитывает тарелки, поскольку в наборе
классов модели нет отдельного класса для тарелок.
